🚀 RANKMYSEO now supports MCP, so you can use RANKMYSEO as the SEO brain for your Claude Code, Codex, or AI agent workflows.

Connect your agent to RANKMYSEO and let it research with your live project data instead of starting from a blank chat.

For Claude Code locally:

```sh
claude mcp add --transport http --scope user rankmyseo-local http://localhost:3001/mcp
```

For Codex:

```sh
codex mcp add rankmyseo --url https://app.rankmyseo.com/mcp
```

Learn more: https://rankmyseo.com/features/mcp

## What you can do

- Ask an agent to research keyword ideas for a domain and save the best ones to RANKMYSEO.
- Compare SERP results while drafting SEO briefs, outlines, or refresh plans.
- Pull backlink and domain context into agent workflows without copy/pasting between tools.
- Check rank tracking data while planning content updates or reporting on SEO progress.
- Use RANKMYSEO with Claude Desktop, Claude Code, Codex, or any MCP-compatible AI tool.

This is the first step toward agent-native SEO workflows: your assistant can inspect the data, reason about it, and help you move faster. ✨
